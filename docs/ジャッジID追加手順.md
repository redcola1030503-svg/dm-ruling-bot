# ジャッジID追加手順

公認ジャッジを新たに追加する(`VALID_JUDGE_IDS`にジャッジIDを追加する)ための手順です。設定の背景や`/login`コマンドの詳細は [judge-login-setup.md](./judge-login-setup.md) を参照してください。

## 前提

- 本番環境はRenderにデプロイされている(`https://dm-ruling-bot.onrender.com`)
- ジャッジIDの命名規則に決まりはない(公式のジャッジ番号、任意のコード名など運用しやすい形式でよい)

## 手順

### 1. 新しいジャッジIDを決める

例:

```text
J003
judge-suzuki
```

既存の値と重複しないIDにする。

### 2. Renderダッシュボードで環境変数を編集する

1. [Renderダッシュボード](https://dashboard.render.com/) にログインする
2. `dm-ruling-bot` サービスを開く
3. 左メニューの **Environment** をクリックする
4. 右上の **Edit** をクリックし、編集モードにする
5. `VALID_JUDGE_IDS` の値欄に、既存の値の末尾へカンマ区切りで新しいIDを追加する

   例: `J001,J002` → `J001,J002,J003`

6. **Save, rebuild, and deploy** をクリックする

### 3. 再デプロイの完了を待つ

- 「Events」または「Logs」タブでデプロイ状況を確認する
- ステータスが **Live** になれば反映完了

### 4. 動作確認する

対象のジャッジ本人のLINEアカウントから、Botに以下を送信してもらう。

```text
/login J003
```

以下のような応答が返れば成功。

```text
ジャッジID「J003」でログインしました。/訂正 コマンドが利用できます。
```

### 5. (任意)ジャッジIDの管理記録を残す

誰にどのジャッジIDを発行したか、社内のメモ等に記録しておくことを推奨します(このリポジトリには実在するジャッジIDの一覧を含めないこと — `VALID_JUDGE_IDS`の値は秘密情報として扱う)。

## ジャッジIDを削除する場合

同様にRenderの `VALID_JUDGE_IDS` から該当IDをカンマ区切りリストから除去し、Save, rebuild, and deployする。既にログイン中のセッションがある場合、DBの`judge_session`テーブルには残るが、`VALID_JUDGE_IDS`から削除したIDでは新規ログイン(`/login`)ができなくなる。既存セッションを即時無効化したい場合は、DB上の該当セッションを直接削除する必要がある(現状、管理UI・コマンドは未実装)。
