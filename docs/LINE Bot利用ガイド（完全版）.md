# DM裁定確認Bot 使い方(完全版)

## 1. このBotについて

デュエル・マスターズの対戦中に発生したルール・カード効果・処理順の疑問について、LINEで自然文の質問を送ると、公式サイト(dm.takaratomy.co.jp)の情報を根拠に裁定候補を回答するBotです。

### 大事な前提

このBotは**AIの記憶だけで裁定を答えることはありません**。必ず以下の公式情報を検索して、それを根拠に回答します。

1. 公式総合ルール(PDF)
2. 公式Q&A
3. 公式ルール変更のお知らせ
4. 公式カードテキスト

該当する公式情報が見つからない場合は、「公式情報からは断定できません」と回答を保留します。これは誤った裁定を無理に出さないための仕様です。**大会等の重要な場面では、最終的に必ずジャッジに確認してください。**

---

## 2. 基本的な使い方

Botとのトーク画面に、質問をそのまま送信するだけです。

```text
自分の《烈しき切札 ドギラゴン逆》が極限ファイナル革命で
相手のカードの効果によってバトルゾーンを離れない状態です。
相手が《～世紀末の善悪～》を召喚し、効果で捨てられた自分の
《「真実を見極めよ、ジョニー！」》を唱えました。
この時《烈しき切札 ドギラゴン逆》は手札に戻りますか？
```

### 質問を書くコツ

- **カード名は《　》で囲む**と、Botがカードを正確に認識しやすくなります(例: 《ボルメテウス・ホワイト・ドラゴン》)
- 状況(誰のターンか、バトルゾーンに何がいるか、何を唱えた/召喚したか)を具体的に書くほど精度が上がります
- 1つのメッセージに複数のカードが登場しても構いません

### 文字数制限

質問は1000文字以内で送ってください。超えるとエラーメッセージが返ります。

---

## 3. 回答フォーマットの読み方

```text
【結論】
（一言でまとめた結論）

【理由】
（なぜその結論になるかの説明）

【処理順】
① ステップ1
↓
② ステップ2
↓
③ ステップ3

確度：高

【公式情報】
・タイトル
URL

・タイトル
URL
```

### 「確度」の意味

| 確度 | 意味 |
|---|---|
| **高** | 質問の状況と論点が完全に一致する公式Q&Aや総合ルール条文が根拠にある |
| **中** | 関連情報はあるが、複数の情報を組み合わせた推論、または類似だが完全に同一ではない事例が根拠 |
| **低** | 直接の根拠がなく、一般的な原則からの推論。断定はできない |

確度が「中」または「低」の場合、回答の末尾に以下のような注記が自動的に付きます。

```text
※この裁定は複数の情報を組み合わせた推論を含みます。重要な場面では大会運営・ジャッジにご確認ください。
```

これが表示された場合、**その回答を鵜呑みにせず、必ず人間のジャッジに確認してください。**

### 【公式情報】について

回答の根拠となった公式サイトのページ(カード詳細、公式Q&A、ルール変更のお知らせ、総合ルール)へのリンクが、最大5件まで表示されます。気になる場合は実際にリンク先を確認することをお勧めします。

---

## 4. 続けて質問する(会話の文脈)

同じトークルーム内で連続して質問すると、直近の会話(最大6件程度)を踏まえて回答します。

```text
あなた: カードAとカードBの場合どうなる？
Bot: 【結論】カードAの効果が先です。...

あなた: じゃあカードCもいる場合は？
Bot: （直前の文脈を踏まえて回答）
```

話題を変えたいときは、状況を具体的に書き直すと誤解を防げます。

---

## 5. コマンド一覧

通常の質問以外に、以下のコマンドが使えます。

| コマンド | 説明 | 誰が使えるか |
|---|---|---|
| `/whoami` | 自分のLINEユーザーIDを表示する(デバッグ用) | 誰でも |
| `/login <ジャッジID>` | 公認ジャッジとしてログインする | 誰でも(有効なジャッジIDが必要) |
| `/logout` | ログアウトする | ログイン中の人 |
| `/訂正 <正しい裁定>` | 直前のBotの回答を訂正として記録する | ログイン中のジャッジのみ |

### 公認ジャッジ向け: 訂正機能について

Botの回答が誤っていた場合、公認ジャッジは訂正を記録できます。記録された訂正は、以後の類似する質問でBotが参考にし、同じ間違いを繰り返さないようにするために使われます(ただし、あくまで参考情報であり、公式情報そのものとしては扱われません)。

使い方:

```text
あなた: /login J001
Bot: ジャッジID「J001」でログインしました。/訂正 コマンドが利用できます。

あなた: 《カードA》で〜した場合、〜できますか？
Bot: 【結論】できます。...(誤った回答)

あなた: /訂正 実際にはできません。〜という理由です
Bot: 訂正を記録しました。今後の類似する質問で参考情報として活用します。
```

ログインしていない状態で `/訂正` を送ると、ログインを促すメッセージが返ります。

---

## 6. 制限事項

- **競技イベント運営ルール(ペナルティ規定など)には対応していません。** 質問すると「公式情報からは断定できません」と返ってきます。これは正しい仕様(未対応範囲であることを正直に伝える)であり、不具合ではありません。
- 短時間に大量の質問を送ると、レート制限により一時的に応答が制限されることがあります(1分あたり60回程度)。
- 回答が返るまで20〜30秒程度かかることがあります。これは公式サイトへの負荷を抑えるための意図的な設計です。
- グループトークなど、LINEの仕様上ユーザーを識別できない場面では、会話の文脈を踏まえた回答や訂正機能は使えず、単発の質問としてのみ扱われます。

---

## 7. よくあるトラブル

| 症状 | 原因・対処 |
|---|---|
| 「公式情報からは明確な裁定を確認できませんでした」と返ってくる | 該当する公式情報が見つからなかった場合の正常な挙動です。カード名の表記を見直すか、ジャッジに確認してください |
| 「質問文が長すぎます」と返ってくる | 1000文字以内に短くして送り直してください |
| しばらく応答がない | 公式サイトへのアクセスに時間がかかっている可能性があります。1分程度待ってから再送してください |
| `/訂正` が使えないと言われる | `/login <ジャッジID>` でログインしてから使ってください |

---

## 8. 免責

このBotの回答は公式情報にもとづく参考情報であり、公式の裁定そのものではありません。大会など重要な場面での最終的な判断は、必ず大会運営・認定ジャッジに確認してください。
