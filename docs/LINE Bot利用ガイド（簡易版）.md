# DM裁定確認Bot 使い方(簡易版)

## これは何？

デュエル・マスターズの対戦中に出てきたルールの疑問を、LINEでそのまま質問すると、公式サイトの情報にもとづいて裁定の候補を答えてくれるBotです。

## 使い方

Botとのトーク画面に、質問をそのまま送るだけです。

```text
《ボルメテウス・ホワイト・ドラゴン》でシールドをブレイクした場合、
S・トリガーは使えますか？
```

カード名は《　》で囲むと認識精度が上がります。

## 回答の見方

```text
【結論】
S・トリガーは使えません。

【理由】
（説明が入ります）

【処理順】
①→②→③...

確度：高

【公式情報】
（根拠となった公式ページのリンク）
```

- **確度：高** → 公式Q&Aや総合ルールに直接の根拠あり
- **確度：中／低** → 推測を含みます。大会などの重要な場面では、ジャッジに確認してください

## 注意

- Botが「公式情報からは断定できません」と答えることがあります。これは無理に答えを出さないための安全策です。
- 誤りに気づいたら、そのままにせず周りに確認してください。
