# Google Play Console 提出用ドラフト・チェックリスト

このファイルはPlay Console入力時の参考用メモです。実際の入力・提出はユーザー本人がPlay Console上で行ってください。

## Data Safety(データセーフティ)フォーム回答案

### データの収集・共有について

**このアプリはユーザーデータを収集していますか？** → はい

### 収集するデータの種類

| カテゴリ | 項目 | 収集理由 |
|---|---|---|
| アプリのアクティビティ | アプリ内での検索履歴 | 質問文・カード名検索クエリを裁定生成に使用(アプリ機能) |
| デバイスまたはその他のID | デバイスID | プッシュ通知の送信先識別のため、端末ごとにランダム生成される匿名ID(アプリ機能) |
| 個人情報 | ユーザーID | ジャッジ・管理者としてログインする際のID(パスワードなし)。アカウント管理機能を使わない一般利用者は入力不要(アプリ機能) |

**収集しない項目の例**: 氏名、メールアドレス、電話番号、住所、位置情報、写真・動画、連絡先、財務情報、閲覧履歴(ブラウザ)、通話履歴

### データの取り扱いについて

- **暗号化して送信していますか？** → はい(すべての通信はHTTPS/TLS)
- **ユーザーはデータの削除を申請できますか？** → はい(プライバシーポリシー記載のメールアドレス宛)
- **このデータは広告目的で使用されますか？** → いいえ
- **このデータは第三者と共有されますか？** → はい(裁定生成のためClaude API・Voyage AI・プッシュ通知のためFirebase Cloud Messagingに送信。詳細はプライバシーポリシー参照)

## コンテンツレーティング質問票 回答案

IARC(国際年齢レーティング連合)の質問票に沿った回答案です。

- **カテゴリ**: リファレンス/ツール、またはユーティリティ(ゲーム攻略・ルール解説アプリ)
- **暴力表現**: なし(カードゲームのルールに関するテキストのみを扱い、暴力・恐怖描写は含まない)
- **性的表現**: なし
- **不適切な言葉遣い**: なし
- **ギャンブル関連の描写**: なし(実際の賭博要素は含まない)
- **ユーザー生成コンテンツ・オンラインでのやり取り**: 質問文はAIへの入力として送信されるのみで、ユーザー間の公開コミュニケーション機能は無い
- **想定レーティング**: 全年齢対象(PEGI 3 / ESRB Everyone相当)

※最終的な回答はPlay Console上の質問票の実際の文言に従って回答してください。上記は想定される回答の方向性です。

## Play Console 提出チェックリスト

### 1. アプリの作成
- [ ] Play Consoleで新規アプリを作成(パッケージ名 `com.dmrulingbot.aiteacher`)
- [ ] デフォルトの言語を「日本語」に設定

### 2. ストア掲載情報
- [ ] アプリ名: `store_listing/title.txt`
- [ ] 簡単な説明: `store_listing/short_description.txt`
- [ ] 詳しい説明: `store_listing/full_description.txt`
- [ ] アプリアイコン(512×512): `store_listing/hires_icon_512.png`
- [ ] フィーチャーグラフィック(1024×500): `store_listing/feature_graphic.png`
- [ ] スクリーンショット(スマートフォン、2枚以上): `store_listing/screenshots/1_home.png` 〜 `5_notification.png`
- [ ] カテゴリ: ツール、またはリファレンス
- [ ] 連絡先メールアドレス: プライバシーポリシー記載のもの
- [ ] プライバシーポリシーURL: `https://redcola1030503-svg.github.io/dm-ruling-bot/mobile-app-privacy-policy.html`

### 3. Data Safetyフォーム
- [ ] 上記「Data Safetyフォーム回答案」を参考に入力

### 4. コンテンツレーティング
- [ ] IARC質問票に回答(上記「コンテンツレーティング質問票 回答案」参照)

### 5. アプリの内容
- [ ] 対象年齢層の設定
- [ ] 広告の有無: なし
- [ ] アプリがニュース系アプリかどうか: いいえ
- [ ] COVID-19関連アプリかどうか: いいえ

### 6. リリース
- [ ] AAB(`build/app/outputs/bundle/release/app-release.aab`)をアップロード
- [ ] **内部テストトラックから開始することを推奨**(審査提出前に自分の実機で最終確認できる。招待した端末のみインストール可能)
- [ ] リリースノート(初回は「初回リリースです」程度の簡潔な内容でよい)
- [ ] 内部テストで問題なければ、クローズドテスト→本番リリースの順に進める、または内部テストの後直接本番トラックへ

### 7. 審査提出
- [ ] すべての必須項目(赤い警告表示がないこと)を確認してから「審査に送信」
